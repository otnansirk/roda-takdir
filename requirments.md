# Roda Takdir Kelas

### Flow user
1. User dapat input daftar nama (ini text area saja dipisahkan oleh enter)
2. user dapat spin untuk membuat kelompok, undian dan juga urutan nama
3. jika untuk kelompok perlu input akan membuat berapa kelompok
4. jika undian nanti hanya memilik 1 nama
5. jika urutan nama berati acar urutan namanya saja jadi list semua nama.


### Tech stack
- Astro - components base 
- local storage


### Experiance
